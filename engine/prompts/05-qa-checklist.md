# QA checklist — run after the engine builds anything, before it goes live
- [ ] Geography matches profile.market.service_area exactly (operators report wrong-state targeting as the #1 build error)
- [ ] Objective and optimization event match profile.primary_result
- [ ] Attribution setting is what the account actually uses
- [ ] Budget matches what was approved, at the right level (campaign vs ad set)
- [ ] Lead form / destination opens and submits
- [ ] Pixel or CAPI event fires on the result
- [ ] Ad names follow the naming convention
- [ ] Everything is still PAUSED until a human publishes
