# Account diagnostic (run once per new profile)
Using the Meta connector on {{ad_account_id}}:
1. List every campaign, ad set and ad with status, objective, budget, spend, impressions,
   clicks, CTR, CPM, results, cost per result and frequency for the last 90 days.
2. Report account structure problems: too many overlapping campaigns, campaigns that
   never spent, legacy or duplicate entities, budgets parked on paused objects.
3. Report the account's own baselines (mean and spread) for CPM, CTR and cost per result.
4. Name the single biggest constraint: creative, audience, offer, landing page, or tracking.
5. State what you could NOT verify.
Output: the numbers, the constraint, and a 7-day plan. Change nothing.
